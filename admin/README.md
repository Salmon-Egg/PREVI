# 관리자 웹 (학생지원팀)

모바일 관리자 시안(`docs/디자인/모바일버전_관리자화면_…pdf`)을 PC 웹으로 옮긴 것. 분실물은 이번 범위가 아님.

| 메뉴 | 하는 일 |
|---|---|
| 처리할 일 | 못한 질문·아쉬워요·공지 정리 실패·푸시 실패 숫자, 학생 수, 답변 성공률 |
| AI 챗봇 | 못한 질문(원인 고르기, 답변 작성, 처리 완료) · 아쉬워요(👎) · 참고 자료(문서 올리기·지우기) |
| 공지 발송 | 새 공지: 학년·학적·학과로 대상 고르기 → 자동 인원 표시 → 학생 화면 미리보기 → 발송 (학생 앱 공지 + 푸시). 보낸 공지: 내용·대상·받은 학생 수 보기, 내리기 |
| 학교 자료 | 학사일정·과목 추가/수정/삭제, 졸업 기준 보기 |
| 공지 수집 | 오늘 모은 공지·정리 완료·확인 필요 숫자, 실패한 공지 원문 확인과 다시 정리 |
| 계정 관리 | 가입 계정 목록(메일·학과·학년·학적·가입일)·검색, 계정 삭제 (관리자 계정은 못 지움) |

## 실행

1. Supabase SQL Editor에서 `supabase/migrations/012_admin.sql` 실행 (한 번만)
2. 저장소 맨 위 `.env`에 `ADMIN_EMAILS=관리자@skuniv.ac.kr` (여러 명은 쉼표), `SUPABASE_SECRET_KEY` 확인 후 서버 실행
3. 여기서 `.env.example`을 `.env`로 복사해 값 채우고:

```bash
npm install
npm run dev
```

http://localhost:5173 → 관리자 학교 메일·비밀번호로 로그인 (학생 앱에서 가입한 계정).
배포는 `npm run build` 후 `dist/`를 아무 정적 호스팅에 올리면 됨. `VITE_API_URL`은 서버 터널 주소로.
