## 폴더 구조

폴더마다 **맡은 사람**이 정해져 있습니다. 내 폴더가 아닌 곳을 고쳐야 하면, 그 폴더 담당자에게 먼저 말해 주세요.

```
seokyeong-ai-secretary/
├─ README.md        ← 지금 보고 있는 파일
├─ docs/            문서 (기획, 규칙, API 명세, 시안)       담당: 조장
├─ app/             모바일 앱 (Expo)                       담당: FE A · FE B
├─ server/          우리 서버 (FastAPI)                    담당: BE A
│  ├─ ai/           AI 부르는 코드, 지시문(prompts)          담당: BE B
│  └─ jobs/         정해진 시각에 도는 작업 (공지 수집 등)    담당: BE A · BE B
├─ supabase/        데이터 표 만들기, 시드 데이터             담당: BE A
├─ .env.example     비밀 설정값 "이름"만 적은 예시 (진짜 값은 절대 올리지 않기)
└─ .gitignore       깃허브에 올리지 않을 파일 목록
```

각 폴더 안의 `README.md`에 그 폴더에 무엇을 넣는지 적혀 있습니다.

## 역할

| 담당 | 맡는 것 |
|---|---|
| FE A | 홈, 마이(M), 내 학업(L), 장학(S), 학사 행정(A) 화면 |
| FE B | 채팅(H), 할 일(T), 알림 센터, 푸시 알림 받기, 개발 빌드 |
| BE A | 데이터 표, API, 공지 수집기, 비서 계산(코드 부분), 알림 보내기, 서버 배포 |
| BE B | AI 설치·호출(`server/ai/`), 지시문, 문서 검색, 챗봇 |

## 진행 방식: 아래층부터 쌓기 (상향식)

아래 단계가 끝나야 위 단계가 막힘없이 진행됩니다.

**10/23: MVP 뼈대가 올라왔습니다.** ①~⑤ 단계의 뼈대(표·시드·API 전부·비서 계산·챗봇·화면 전부)가 가짜 AI와 예시 공지로 끝까지 동작합니다.
각자 맡은 카드는 이 뼈대를 **진짜로 바꾸고 다듬는 일**입니다. (진짜 AI 연결, 학교 게시판 수집, 실제 학사요람, 시안대로 디자인, 푸시 빌드, 배포)
실행 방법은 [server/README.md](server/README.md) · [app/README.md](app/README.md)를 보세요.
