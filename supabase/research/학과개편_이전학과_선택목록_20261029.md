# PREVI — 개편 전 학과·전공 선택 목록과 적용 원칙

조사일: 2026-10-29

## 결론

이번 선택 범위는 2025 개편 직전 학과와 컴퓨터공학과·전자공학과다. 현재 FE 목록은 2026 중심에 옛 학과 2개만 추가한 상태라 기존 재학생의 학과가 누락돼 있다. 컴퓨터공학과·전자공학과를 비롯한 아래 옛 소속을 가입 후 처음 설정과 학적정보 수정 양쪽에 추가해야 한다.

2025 개편 공식 안내는 2024학번까지 재학생의 소속·학위 유지와 신설 학부 전과 선택을 설명한다. 최신 모집 단위에서 사라졌다는 이유로 재학생의 학과를 지우면 안 된다. 다만 이 안내는 2025 개편 대상이며 모든 과거 폐과의 존속을 보증하지 않는다. [학교 안내](https://www.skuniv.ac.kr/notice/46583)

컴퓨터공학과·전자공학과는 2025가 아니라 **2023학년도에 통합**됐다. 2025-02-09 컴퓨터공학과 안내에는 2024년 2학기 이후 복학 시 원래 입학 학과로의 학적 회복과 학적별 다른 졸업 경로가 명시돼 있다. 학번이나 화면에 보이는 학과명만으로 졸업 교육과정을 확정하면 안 된다.

## FE 전달 자료

기계 판독 자료: `department_catalog_history.json` — 선택 항목 50개. 이 수는 대학의 공식 학과 수가 아니라 학부·세부전공·옛 이름을 포함한 화면 선택값 수다.

- `entries[].name`: 저장할 소속명. 현재 목록과 이름 기준으로 중복 제거한다.
- `parent`: 학부에 속한 전공의 상위 소속. 학부 이름만 저장된 기존 계정도 유지한다.
- `admission_year_hint.to`: 옛 이름의 신입학 추천 상한. 선택 차단이나 졸업 기준 연도로 사용하지 않는다.
- `related_names`: 통합·개편 계보. 교육과정 동등성이나 자동 졸업 기준 연결을 뜻하지 않는다.
- `automatic_graduation_mapping`: 모두 false. 아래 확인 절차 전에는 졸업 기준을 복사하지 않는다.
- `source_ids`: 아래 출처 목록의 근거. PDF 쪽 번호는 파일의 실제 1-based 페이지다.

## 선택 목록의 범위

2025 개편 직전인 2024 요람의 소속을 중심으로 하고, 사용자가 요청한 컴퓨터공학과·전자공학과(2023 통합 전)는 예외로 포함한다. 컴퓨터과학과처럼 오래전에 바뀐 이름까지 선택지에 늘리지 않는다.

이전 초안의 오래된 명칭 15개를 기본 선택 목록에서 제외했다. 제외 항목은 JSON의 `out_of_scope_names`에만 기록하며 FE 선택 항목으로 읽지 않는다. 이미 저장된 사용자 정보의 자동 변경이나 삭제를 뜻하지 않는다.

## 폐과 제외와 자료 충돌 처리

‘모집 중단’, ‘통합’, ‘명칭 변경’, ‘행정상 폐과’를 ‘재학생도 존재하지 않는 완전 폐과’와 구분한다. 현재 공개 자료만으로 모든 학과의 재적 인원 0명을 확정할 수 없으므로 완전 폐과 전체 명단이라고 주장하지 않는다.

- **광고홍보콘텐츠학과**: 공식 2024 모집 안내에서 폐지, 광고홍보영상학과 신설로 구분. 명칭 변경으로 확정하지 않아 요청한 기본 추가 목록에서 제외. 기존 저장 계정은 유지하고 현 재적자·승계 확인 후 별도 검토.
- **아동가족학과**: 2024 요람 연혁에 등장하지만 같은 요람 교육과정·최종 모집 안내는 아동청소년학과. 독립 선택값 추가 보류.

## 컴퓨터공학과·전자공학과 졸업 자료

### 컴퓨터공학과

[현 학적별 안내](https://ce.skuniv.ac.kr/10630)는 컴공 졸업과 전컴공 졸업의 전공핵심·학적 조건을 분리한다. [학과 졸업요건](https://ce.skuniv.ac.kr/ce_requirements_for_graduation)은 졸업작품, 자격증, 전공이수 평가와 CE1999 이수를 안내하며 영어 항목은 2025 폐지를 명시한다. 페이지 하단에 과거 캠프 항목이 남아 있어 최신 공통 폐지 공지와 대조해야 한다. 평가의 조합·면제·학과 승인 조건은 사람 확인 없이 자동 충족 처리하지 않는다.

### 전자공학과

[현 학적별 안내](https://ee.skuniv.ac.kr/index.php?document_srl=135318&l=ko&listStyle=webzine&mid=ee_notice&oldact=dispBoardWrite&order_type=desc&sort_index=readed_count)는 기존 전자공학과의 전공핵심 및 전자회로·공학종합설계·작품·논문 조건을 통합 학과와 구분한다. 해당 학생의 학적회복·전과·이수 인정 여부를 확인한다. 오래된 공지의 130·140학점을 현재 모든 학번에 그대로 적용하지 않는다.

### 기존 적재 자료와의 관계

기존 `graduation_catalog_legacy_2024.json`의 컴퓨터·전자공학과는 계산 기준 미확인 상태였다. 이번에는 학과별 공식 졸업 안내 출처를 확보했다. 다만 전체 학번별 총학점·교양·면제까지 확정한 것은 아니므로 이번 선택 목록을 `grad_requirements` 수치로 바꾸거나 기존 임베딩 문단을 덮어쓰지 않는다.

## 화면·서버 반영 명세

1. 현재 `app/lib/constants.ts`의 DEPTS와 이 자료의 selectable 항목을 합친다. 실제 작업은 최신 통합본에서 한다. 로컬 예전 브랜치의 2개짜리 목록으로 되돌리지 않는다.
2. 가입 후 처음 설정(onboarding)과 마이페이지 학적 수정(status)은 같은 목록을 참조한다. 복수·부전공에도 같은 명칭 원천을 쓰되 해당 전공의 실제 신청 가능 여부는 별도 확인한다.
3. 화면에서는 ‘현재 학과·전공’과 ‘개편 전 학과·전공’을 나눠 검색할 수 있게 한다. 입학연도는 추천 정렬에만 사용한다. 편입·재입학·전과·복학자는 다른 시기 이름도 고를 수 있어야 한다.
4. 학교 포탈의 현재 소속을 저장한다. 현재 소속·입학 당시 학과·적용 졸업 교육과정은 다른 정보이므로 자동 변경하지 않는다. 새 필드나 API 형식 추가는 팀 문서 합의 후 별도 구현한다.
5. 졸업 기준이 없더라도 성적·시간표까지 오류 화면으로 가리지 않는다. 졸업 영역에는 ‘적용 교육과정 확인 필요’와 확인된 소속·입학연도를 보여준다.
6. 기준 연결은 명시된 교육과정과 확인된 학번으로 한다. 컴퓨터공학과→전자컴퓨터공학과, 소프트웨어학과→컴퓨터소프트웨어전공을 일괄 치환하거나 최신 학점 기준을 복사하지 않는다.
