# 서경대학교 학과·전공별 졸업요건 정리

## 실제 적용 결과 (2026-10-29)

- 팀 Supabase에 신규 최소 기준 147행, 출처 문서 69개, 문단 240개를 추가했습니다.
- 적재 전 기준 6행을 백업과 비교해 변경 없이 보존됐음을 확인했습니다. 총 계산 기준은 153행입니다.
- 새 가상 계정으로 컴퓨터소프트웨어(2025), 헤어디자인(2025), 경영학부(2024), 스포츠앤테크놀로지(2024), 글로벌관광경영(2026) API의 총학점·전공·교양 최소 기준을 확인했습니다.
- 일반 학생 토큰으로 새 출처 문서·문단 읽기 권한을 확인하고 검사 계정을 삭제했습니다.
- 벡터 미색인 문단은 240개입니다. 이 PC는 EMBED_MODEL이 설정되지 않아 벡터를 만들지 않았습니다. 기존 임베딩은 수정하거나 삭제하지 않았습니다.
- GPU PC에서 실제 임베딩 설정 후 다음 명령으로 이번 자료의 빈 임베딩만 채웁니다.

```powershell
python -m server.scripts.load_graduation_catalog --apply --embed --backup-dir C:\PREVI-backups
```

확인일: 2026-10-29. 공식 2026·2024 대학요람과 현행 폐지 공지를 대조한 자료입니다.

계산용 최소 기준 147행 / 56개 학과·전공, 검색용 문서 69개.

## 적용 원칙

- 학교 공통 외국어 졸업요건과 CREOS·SKON·DREAM 비교과인증은 2025년 8월 졸업예정자부터 폐지되었다. 학과의 별도 졸업시험·작품·교과 요건과 혼동하지 않는다.
- 총학점과 큰 영역 학점은 확인된 최소 기준이다. 교양 영역별 이수, 전공핵심, 학년별 교과목, 편입·재입학·학과 변경·다전공·대체 인정은 별도 확인한다.
- 2025학번부터 미래융합학부1·2 및 자유전공학부의 단일전공 공통 최소 기준은 총 130학점, 전공 60학점, 교양 37학점이다(PDF 96쪽).
- 2025학번부터 군사·아트앤테크놀로지·공연예술·디자인영상·미용예술 계열 공통 최소 기준은 총 120학점, 전공 48학점, 교양 32학점이다(PDF 97쪽). 스포츠앤테크놀로지학과의 별도 상향 기준은 PDF 369쪽을 우선 적용한다.
- 2017~2024 입학자의 공통 최소 총학점은 120, 전공은 48이며 교양은 2017~2019학번 22, 2020학번 28, 2021~2024학번 33이다(PDF 98~99쪽). 학과별 상향 기준과 학과명 변경을 따로 확인한다.
- 2026 요람의 일부 학과 표에는 공통 폐지 공지와 맞지 않는 과거 인증 문구가 남아 있다. 이를 현재 필수 요건으로 자동 등록하지 않는다. 학과 자체 어학시험의 존속 여부는 학과 확인 대상으로 남긴다.
- 최종 졸업 충족 여부와 개인별 인정은 서경포탈의 졸업요건 충족 현황 및 학과 사정을 확인해야 한다.

학과별 내규의 세부 이수·시험·작품·대체인정은 확인 필요로 남깁니다. 데이터 등록은 졸업 가능 판정을 의미하지 않습니다.
2023~2024의 기존 학과명과 2025~2026의 개편 전공명을 단순 치환하지 않습니다. 확인하지 않은 학번은 새 계산 행을 만들지 않았습니다.
외국인 전담학과와 융합전공은 별도 적용합니다. 융합 36/42학점을 학사학위 전체 총학점으로 사용하지 않습니다.

## DB 적재·검사

기존 grad_requirements, documents, doc_chunks 표만 사용하며 새 SQL 실행은 필요하지 않습니다.
`python -m server.scripts.load_graduation_catalog`는 계획만 출력합니다.
`python -m server.scripts.load_graduation_catalog --apply --backup-dir <저장소 밖 백업 폴더>`로 추가합니다.
기존 학과·학번 계산 행은 덮어쓰지 않습니다. 기존 요람·장학 문서 및 임베딩을 삭제하지 않습니다.
새 문서와 문단은 같은 제목·내용이면 재실행해도 중복 추가하지 않습니다. 기존 내용이 달라졌으면 삭제 대신 중지합니다.
GPU PC에서 실제 임베딩 모델을 설정한 뒤 같은 명령에 `--embed`를 붙이면 이번 자료의 빈 768차원 임베딩만 채웁니다.
기존 `load_yoram`을 이 목적으로 다시 실행하지 않습니다. 가짜 AI 모드에서 기존 임베딩을 지우는 재적재를 하지 않습니다.
임베딩 전에는 숫자 계산용 최소 기준을 사용할 수 있지만 실제 벡터 검색에 새 문서가 포함됐다고 간주하면 안 됩니다.
원본 자료 JSON은 graduation_catalog_2026.json과 graduation_catalog_legacy_2024.json입니다. 출처·입학년도·미확정 항목을 포함합니다.
