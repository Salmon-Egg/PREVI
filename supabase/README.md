# supabase/ — 데이터 표와 시드 데이터

담당: BE A

## 여기에 들어갈 것
```
supabase/
├─ migrations/   표 만들기 SQL (001_init.sql, 002_… 순서대로)
└─ seed/         처음에 넣어 두는 데이터
                 - 졸업 기준 (소프트웨어학과, 전자컴퓨터공학과)
                 - 학사일정, 과목 목록, 학사요람 문서
                 - 시연용 가상 학생 4명 (기획안 페르소나: 1학년 김새내 ~ 4학년 홍길동)
```

표 설계는 `docs/05_데이터_표.md`를 따릅니다. 표를 바꾸면 그 문서도 함께 고칩니다.
실제 학생 정보는 넣지 않습니다.
