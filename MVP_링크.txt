[내 PC에서 직접 켜기]
cd app
npm install
copy .env.example .env
npx expo start           → w 누르면 웹, QR은 Expo Go

- 서버 없이 화면만: .env에서 EXPO_PUBLIC_USE_MOCK=1
- 실제 서버(통합본): USE_MOCK=0, DEV_LOGIN=0, EMAIL_DOMAIN=skuniv.ac.kr
  + EXPO_PUBLIC_SUPABASE_URL·EXPO_PUBLIC_SUPABASE_ANON_KEY(단톡방 공지 값) + 서버 켜기(server/README.md)
  시연 계정 비밀번호는 조장에게 (깃에 없음)
- 남은 순서(푸시·APK)는 app/FE_구현_정리.md '실제 서버 연결·제출 준비'
