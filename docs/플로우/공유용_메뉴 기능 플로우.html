2. AI 비서가 메뉴를 이어 주는 흐름

학생이 한 화면에서 행동하면, 비서가 다른 메뉴에 결과를 만들어 줍니다.

학생 화면AI 비서가 자동 처리관리자

① 성적 입력 → 장학금 발견

L-10 성적 입력→자격 재계산→홈 브리핑 "신청 가능 1건"→S-2 공지 요약→신청 완료 체크→S-3 신청 내역

② 졸업 마감 챙기기

학사요람·성적 대조→오늘 챙길 일 "심사 신청 D-DAY"→T-2 할 일 상세→H-2 채팅으로 묻기→신청 후 T-3 완료

③ 휴학 결정

M-4 학적 → 휴학→관련 규정 찾기→A-3 휴·복학 안내→복학 기한 등록→T-1 할 일 목록

④ 분실물 찾기 (부가)

C-3 분실 신고+AD-7 습득물 등록→매칭 92%→T-4 알림→C-4 상세 → C-5 수령 신청→AD-6 승인

⑤ 챗봇이 모르는 질문

H-2 "근거 문서가 없어요"→미응답 질문 기록→AD-2 확인→AD-3 문서 추가→같은 질문에 답변
