AI가 작동하는 21곳을 정리했습니다. 모든 흐름은 시작 → 받는 정보 → AI가 하는 일 → (코드가 하는 일) → 보이는 화면 순서로 읽습니다. 화면 번호는 메뉴 구성 문서와 같습니다.

자동학생이 모르는 사이에 · 매일 아침, 정보가 바뀔 때

1공지 해석

새 공지 등록→공지 원문→대상·조건·마감·서류 뽑기 + 3줄 요약→A-1 공지 · S-2 AI 요약

2대상 분류

공지 해석 끝→정리된 공지→학년·학적·학과 대상 분류→A-1 나에게 해당 · A-2 학년별 일정

3자격·요건 판정

매일 아침 · 성적·학적 변경→규정 조건 + 내 정보→규정 문장을 비교할 수 있는 조건으로 변환→대조 · 학점 계산→S-1 판정 · L-2 남은 요건

4우선순위 정하기

판정 끝→할 일 후보→D-day 계산→놓쳤을 때 피해 크기 판단 → 순서→오늘 챙길 일 · T-1

5브리핑 문장

정렬 끝→상위 할 일 3개→말풍선 한 줄 · 메뉴 칸 상태 문구 작성→홈

6근거 설명

할 일 생성→조건 + 내 정보→"왜 나에게 해당하는지" 작성→T-2 · S-1

7추천 질문

홈 열 때→학년 · 학적 · 이번 주 일정→지금 궁금할 질문 3개 고르기→홈 하단 · H-1

8알림

마감 전날·당일 · 새 판정→할 일→짧은 알림 문장 작성→설정 시간에 발송→T-4 · 푸시

9분실물 매칭(부가)

습득물 등록→습득물 + 분실 신고들→설명 유사도 비교→일치율 점수 계산→T-4 알림 · C-1 배너

요청 시학생이 누르거나 물을 때

10의도 파악

질문 입력→질문 문장→내 정보 질문 · 문서 질문 · 분실물 중 분류→11 또는 12로

11문서 근거 답변

문서 질문→관련 문단 검색→근거로 답 작성 + 출처→H-2·근거 없으면 "모른다" → 19로

12내 상황 답변

내 정보 질문→3번 계산 결과→쉬운 문장 + 요약 카드로 작성→H-2

13다음 행동 버튼

답변 생성→답변 내용→맞는 버튼 고르기 (알림 받기 · 신청 페이지 · 화면 이동)→H-2→누르면 T-1 등록

14맥락 이어받기

T-2 "채팅으로 묻기"→할 일 내용 · 근거→대화의 첫 맥락으로 설정→H-2 설명 없이 바로 질문

15학적 변경 안내

M-4 휴학으로 변경→새 학적 상태→관련 규정 검색 · 요약 (장학금 영향, 복학 기한)→A-3 안내+T-1 기한 등록

16사진 분석(부가)

C-2 사진 업로드→사진→분류·색상·특징 추출+이름·학번·카드번호 찾아 가림→C-2 자동 입력 · AD-7

17분실 신고 정리(부가)

C-3 자유 입력→설명 문장→물건·색상·장소·시간 뽑기→C-3 정리된 신고→9번 매칭으로

18본인 확인 질문(부가)

C-5 수령 신청→습득자 메모→확인 질문 생성→학생 답변→메모와 대조→AD-6 일치 여부

20문서 학습

AD-3 문서 업로드→PDF · 공지→문단 나누기 · 검색용 저장 · 요약→11번 답변 · 1번 해석에 바로 반영

21발송 대상 해석

AD-4 대상 문장 입력→"3학년 이상, 소득 8분위 이하"→검색 조건으로 변환→대상 학생 수 계산→해당 학생 홈 브리핑

흐름끼리 이어지는 곳

  • 1 → 2 → 3 → 4 → 5: 매일 아침 한 번에 이어서 돌고, 그 결과가 홈 화면이 됩니다.
  • 10 → 11 또는 12: 질문이 들어오면 10번이 처리 경로를 정합니다.
  • 3 → 12: 내 상황 질문에는 아침에 계산해 둔 결과로 답합니다.
  • 11 → 19 → 20 → 11: 모르는 질문은 관리자가 문서를 보강하면 다음부터 답합니다.
  • 17 → 9: 정리된 분실 신고는 자동 매칭으로 넘어갑니다.
  • 학점 합산, D-day 계산, 시간 중복 확인처럼 숫자가 틀리면 안 되는 일은 AI가 아니라 코드가 처리합니다.
