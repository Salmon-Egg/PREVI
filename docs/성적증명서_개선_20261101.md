# 성적증명서 추출·미리보기 보완

실제 성적증명서를 제공받지 않은 상태에서 코드·합성 입력으로 확인된 결함을 수정했다. 실제 문서의 누락률·인식률이 검증된 것은 아니다.

## 바꾼 동작

- 성적 입력은 현재 개설과목 courses DB와 대조하지 않는다. 폐지 과목·과거 학기 과목도 받아들인다.
- PDF 글자는 표 배치를 유지하는 pypdf layout 모드로 읽는다. 스캔 PDF·비활성화된 사진 인식을 새로 켜지 않는다.
- 1,500자 조각을 보낼 때 앞부분의 연도·학기 머리글을 같이 넘긴다. 조각별 AI 실패를 빈 목록으로 삼켜 일부만 성공한 것처럼 반환하지 않는다.
- AI가 반환한 과목은 값이 불명확해도 미리보기에 남긴다. 명칭이 없는 항목만 dropped로 집계하고, AI가 통째로 누락한 과목 수가 이 숫자에 포함되지 않을 수 있음을 표시한다. 약어·성적이 있는 일부 미인식 원문 행도 추가 확인 대상으로 표시한다.
- 입학연도와 수강연도의 차이로 학년을 계산하지 않는다. 추출된 연도·학기를 보여주고, 사용자가 각 수강 학기를 1-1~6-2 중 실제 저장할 학기로 연결해야 한다. 계절학기는 기존 저장 구조에 칸이 없어 미리보기에 제외 사유를 표시한다.
- 미리보기에서 과목명·학점·성적·이수구분을 수정할 수 있다. 비어 있는 필수값과 학기 연결, 원문 대조 확인이 끝나야 저장한다.
- 원문 행에 성적이 하나로 확인되면 그 값을 사용한다. 예: AI C+ / 원문 D+ → D+. 원문 N/A는 성적을 복원하지 않고 저장 대상에서 제외한다. 한 행에 두 과목의 성적이 섞이면 추측하지 않고 직접 확인으로 남긴다.
- 전공 핵심·심화·기초·선택과 자유·일반선택을 구분한다. 미확인 영역을 교양선택으로 채우지 않는다. 자유·일반선택은 총 이수학점에는 포함하되 교양 학점으로 자동 합산하지 않고 인정 기준 확인을 표시한다.
- 동일 과목·학기에 서로 다른 결과가 있으면 마지막 값으로 조용히 덮어쓰지 않는다. 미리보기에서 중복 내용을 확인·제거한 뒤 저장한다.

## 실제 증명서 대조 후 변경

실제 증명서 PDF 1건을 이 PC에서만 읽어 확인했다. 파일과 내용은 저장소에 넣지 않았다. 위 내용 중 달라진 동작은 다음과 같다.

- 원인: 증명서가 A0·B0를 `Ao`·`Bo`로 찍어 성적으로 인식하지 못했고, 두 칸 표가 한 줄에 합쳐져 원문 행 대조에서 성적이 비었다. AI 추출에서는 과목 누락도 생길 수 있었다.
- 서경대 양식은 코드(`parse_courses`)로 읽고 AI를 거치지 않는다. 다른 양식만 AI가 읽는다. 표본 PDF에서 47행을 모두 읽었고, 학기별 학점과 총 취득학점 121이 증명서와 일치했다.
- 학기는 직접 연결하지 않고 수강한 학기 순서로 1-1~4-2를 채운다. 휴학한 학기는 세지 않고, 9번째 학기부터는 4-2로 묶는다. 다르면 학생이 묶음별로 바꿀 수 있다.
- 읽은 학점 합과 증명서 총 취득학점을 비교해 표시한다. `대조 완료` 버튼은 없앴고, 빈 값이 없으면 저장할 수 있다.
- 재수강 표시 `:R`은 과목명에서 뺀다. 졸업 필수 과목과 이름이 맞게 하기 위해서다.
- 양식 1건으로만 확인했다. 계절학기 머리글과 학번·학과가 다른 증명서는 실제 표본으로 확인하지 못했다.

## 배포와 호환

- DB 마이그레이션 없음. 기존 저장 성적·프로필·시간표를 수정하거나 다시 분류하지 않는다.
- 서버와 학생 웹을 함께 반영해야 한다. 업로드 요청에 `preview_version: 2`가 필요하다. 오래된 앱은 업데이트 안내(409 TRANSCRIPT_PREVIEW_UPDATE_REQUIRED)를 받는다. 잘못된 학년을 자동 저장하도록 구버전 동작을 유지하지 않는다.
- 최신 APK도 다시 빌드해야 한다. 공지 사진용 VISION_MODEL·NOTICE_OCR_DIR 설정은 바꾸지 않는다.
- `AI_FAKE=1 .venv/bin/python -m pytest server/tests -q`로 서버 검증. 운영 .env의 AI 설정을 바꾸는 명령이 아니다.
- 프런트엔드 보조 검증: `node scripts/check-transcript-preview.cjs`, 타입 검사, Expo lint, 웹 export.

## 남은 한계

- 여러 열·복잡한 표·깨진 PDF 글꼴은 실제 익명화 표본으로 추가 검증해야 한다. 원문 행을 특정하지 못하면 성적·이수구분을 자동 확정하지 않는다.
- AI가 과목 자체를 누락한 모든 경우를 검출하지는 못한다. 과목 수·원문 대조가 필요하다.
- N/A로 대체된 이전 D+ 같은 과거 성적을 복원하지 않는다. N/A 이력은 이번 미리보기에만 표시하고 현재 grades 표에는 저장하지 않는다.
- 기존에 잘못 저장된 성적은 이 변경으로 자동 정정되지 않는다. 기존 과목 중복은 기존 API 규칙대로 저장 실패 목록에 표시한다.
