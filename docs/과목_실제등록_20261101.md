# 시간표 과목 실제 등록 결과

2026-11-01 KST, BE A 요청에 따라 실제 관리자 업로드 API를 호출했다.

- 학교 원본: 공지 31번의 `2026-2학기 강의시간표_20260826v2.hwp`.
- 공개 파일 키: `2026/08/8e7987db-89b9-45c1-a7a4-9b029385ccb5.hwp`.
- 경로: `POST /admin/courses/import`. 파일 업로드와 학생 검색 확인에 제출용 관리자·학생 계정을 사용했고, 검사 세션은 각각 로그아웃했다. 비밀번호·토큰은 기록하지 않는다.
- 업로드 응답 HTTP 201: 추가 과목·분반 1,252개, 기존 중복 0개, 해석하지 못한 과목명 119개.
- 실제 DB 등록 전 0행 → 등록 후 전체 페이지 조회 1,252행.
- 학생 계정 `GET /courses?q=College English 2`: HTTP 200, 검색 결과 6개.
- 기존 학생의 시간표를 수정하거나 새 시간표 항목을 추가하지 않았다.

## 남은 범위

- 수업 시간·학점 등을 읽지 못한 119개 과목명은 등록 결과 파일에 남겼으며 자동 등록하지 않았다. 모든 개설 강좌가 등록된 것은 아니다.
- 학생 앱에서 과목 선택 → 시간표 저장 → 실제 겹침 경고까지 누르는 UI 시험은 이번 확인에 포함하지 않았다.
- 원래 점검표 5번의 'courses 0개로 검색 불가' 문제는 해결됐다.
