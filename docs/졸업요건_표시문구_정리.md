# 졸업요건 표시 문구 정리

2026-10-29 · 사용자 요청: 졸업 화면에서 출처·긴 설명 제거, 짧고 읽기 쉬운 요건 표시.

- 학점·판정 계산은 유지하고 응답 필드 형식도 유지한다.
- 필수교양 선택군은 짧은 제목과 대표 과목 2개 이내의 다음 줄로 표시한다. 택1 표기를 유지한다.
- 학과의 긴 인증·심사·예외 설명은 ‘학과별 추가 졸업요건 확인’ 항목으로 묶는다. 확인 불가 상태(null)는 그대로 유지한다.
- 출처 URL과 상세 원문은 DB `required_courses[].details` 및 적용 전 백업에 보존한다. `/graduation` 응답의 요건명에는 내려주지 않는다. 원문·출처는 추후 앱 정보/상세 안내 화면에 연결할 수 있다.
- 과목명을 직접 대조하는 일반 필수 교과목은 그대로 유지한다. 선택 과목 모두를 각각 필수로 만들거나 임의 완료 판정하지 않는다.
- 154개 등록 기준에 표시 정리를 적용했다. 앱 화면에 DB 문구를 직접 내려주는 기존 서버도 해당 변경을 즉시 볼 수 있다. 백엔드의 URL 제거·짧은 확인 안내 코드는 별도 서버 반영이 필요하다.
- 공통 교양 추가 스크립트는 표시 전 원문도 중복 검사하므로 정리 후 재실행해도 원래 긴 항목을 중복 추가하지 않는다.

화면의 카드 간격·글꼴·접기 UI는 이번 백엔드 변경에 포함하지 않는다. 상태 아이콘과 학점 수치는 유지하며 출처 화면 자체는 아직 추가하지 않았다.
