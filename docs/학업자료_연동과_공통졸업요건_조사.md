# 학업자료 연동·공통 졸업요건 조사

확인일: 2026-10-29

## 현재 빈 화면의 원인

DB를 학과·학번별로 집계한 결과 컴퓨터공학과 2021학번은 최소 기준 보완 후 조회 가능하지만 해당 학과·학번 계정 2개 모두 과목별 성적 행이 없었다. 기본 구조는 학교 데이터를 자동 수신하는 방식이 아니라 PREVI grades에 저장된 성적을 계산한다. 총 기준이 표시되는 것과 개인 이수 과목이 존재하는 것은 다르다.

소프트웨어학과 2025·2026학번도 정확한 기준 행이 없었다. 개편 전 학과명을 새 학번에 선택한 상태일 수 있으므로 2025 이후 컴퓨터소프트웨어전공 기준을 확인 없이 복사하지 않는다. 전체 대학·모든 학번의 누락이 해결됐다는 뜻은 아니다.

## 공통 교양: 최신 근거

- [2026 교양교육과정 개편 공지](https://www.skuniv.ac.kr/notice/60616): 2026년 8월 졸업대상부터 적용되는 표·대체수강·면제 규정. 이번 정리의 우선 근거.
- [교육과정 안내](https://www.skuniv.ac.kr/curriculum): 학번·계열별 최소 학점 및 교육과정.
- [2025 교양필수 개편 HWP가 붙은 공지](https://www.skuniv.ac.kr/notice/51758): `2025 핵심역량 교양팰수 개편 안내_게시부_250210.hwp`. 공개 HTML의 data-file-key는 `2025/10/fdd651d73333b9ce93703bc6d4f414af.hwp`. 첨부를 찾았지만 HWP 본문을 별도 변환한 것은 아니며 최신 공지의 공개 표를 기준으로 한다.
- [2026 영어 이수면제 안내](https://www.skuniv.ac.kr/notice/65932): 면제와 취득학점을 구분한다.

2021~2024학번 교양 33학점, 선택 5개 영역별 1과목 이상·선택 합계 15학점 이상을 확인한다. 교양필수는 창의·문제해결, 대인관계, 영어1, 영어2, 자기계발, 실무의 각 선택군을 확인한다. 정확한 선택 교과명은 `supabase/research/common_general_education_2026.json`에 정리했다. 2025 이후 교과는 같은 규칙으로 복사하지 않는다.

World English 1·2는 2026년 8월부터 필수에서 빠진다. World Wide English 1·2와는 다른 이름이다. 영어 면제 승인을 받았어도 취득학점이 추가되는 것은 아니다. 총학점·교양 합계만 충족했다고 필수 교과까지 충족한 것으로 판단하지 않는다.

## 서경포탈에서 가져오기

확인한 공식 경로:

1. 졸업 기준·개인 충족 현황: 서경포탈 → 학부 → 졸업 → 졸업요건 충족 현황 조회. [학교 안내](https://www.skuniv.ac.kr/notice/58983)
2. 성적증명서: 서경포탈 → 학부 → 증명 및 발급 → 증명서 발급 → 성적증명서 신청 → 출력. [학교 안내](https://www.skuniv.ac.kr/notice/67706)

외부 서비스가 학생 동의를 받아 성적을 직접 수신하는 공개 API·OAuth 연동 문서는 이번 공개 자료 조사에서 확인하지 못했다. 없다고 확정한 것은 아니다. 학교 정보전산원·교무처에 제공 API, 신청 절차, 이용 허가, 전달 가능 항목을 확인해야 한다. 로그인 뒤의 PDF 저장·엑셀 내보내기 가능 여부도 실제 포탈 화면에서 확인 전이다.

현실적인 단기 경로는 사용자가 본인 포탈에서 확보한 성적표/조회 표를 PREVI에 올리고, 추출 결과를 검토·수정한 뒤 저장하는 방식이다. 이는 제안이며 현재 파일 업로드·PDF/표 파서는 구현되지 않았다. 포탈 비밀번호를 PREVI 서버에 저장하는 기능은 추가하지 않았다.

수입에 필요한 최소 열은 학기, 과목명, 학점, 성적, 이수구분이다. 교양 영역·학수번호·재수강 대체·포기·면제·편입 인정 정보가 없으면 세부 충족은 확인 필요로 유지한다. 에타의 2021년 1학기와 기존 API의 학년-학기(1-1)는 자동 동치로 가정하지 않는다. 복학 등으로 학년도와 학년이 다를 수 있다.

## 에브리타임

[공식 서비스](https://everytime.kr/)에서 제3자용 성적 연동 API, 공식 CSV/PDF 내보내기 사양을 이번 공개 조사에서는 확인하지 못했다. 따라서 자동 연결 가능·내보내기 가능이라고 확정할 수 없다. 로그인된 앱 화면의 공유·내보내기 지원 또는 운영사 협력 여부를 추가 확인해야 한다.

사용자가 직접 작성한 학점계산기 자료가 있다면 후보 입력 자료로 사용할 수 있지만 학교가 확정한 성적·대체 인정과 일치한다고 보장하지 않는다. 포탈 성적을 기준 자료로 우선하고, 에타 자료는 실제 제공되는 표/파일 형태를 확보한 뒤 검토형 가져오기를 설계하는 편이 적합하다. 비공식 API나 자동 로그인 수집기는 구현하지 않았다.

## 반영과 미완료를 구분

- 완료: 실제 DB 익명 집계, 공식 최신 교양 표·HWP 첨부 공지·포탈 메뉴 경로 조사, 교양 선택군 구조화.
- DB 반영 완료: 2021~2024학번 기준 81개와, 확인된 2025~2026학번 계열 기준 70개에 교양 확인 항목을 추가했다. 합계 151개 기준이며 중복 추가하지 않는다. 2025 이후는 미래융합·자유전공과 일반 계열을 구분하고 외국인 전담학과·미확인 조합은 제외했다. 실제 이수·면제를 모르는 항목은 manual로 둔다. 기존 학점 수치·성적·학과 심사 조건을 보존하고 백업했다.
- 미완료: 실제 성적 파일 샘플 검증, 업로드/미리보기/중복 방지/가져오기 구현, 학교 공식 연동 승인·연결, 에타 내보내기 확인, 개인별 과목 충족 자동 판정.

학교 계정 비밀번호는 전달받을 필요가 없다. 파일 방식을 검증하려면 본인 계정에서 직접 출력한 성적표의 개인정보를 가린 샘플과 제공되는 내보내기 형식을 먼저 확인한다.
