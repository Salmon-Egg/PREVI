# 컴퓨터공학과 2021학번 졸업 기준 보완

2026-10-29

## 원인과 조치

가입 학적이 `컴퓨터공학과`, 입학연도가 `2021`인 계정은 정확히 일치하는 `grad_requirements` 행이 없어 졸업 조회가 실패했다. 통합 후 전자컴퓨터공학과나 컴퓨터소프트웨어전공으로 치환하지 않고 별도 기준을 보완했다.

- 일반 신입학·단일전공 최소 총학점 120, 전공 48, 교양 33.
- 근거: [2026 대학요람 실제 PDF 98쪽 — 2017~2024 입학자 교육과정 표](https://www.skuniv.ac.kr/wp-content/uploads/2026/04/48589058-f7a3-429b-a64f-9288e740ac34.pdf#page=98).
- 학과 별도 심사·필수 교과·작품·자격증·대체 인정: [컴퓨터공학과 졸업요건](https://ce.skuniv.ac.kr/ce_requirements_for_graduation), [현 학적별 수강·졸업 안내](https://ce.skuniv.ac.kr/10630).
- 적용 범위는 2021학번 컴퓨터공학과로 한정한다. 다른 학번·통합 전 전자공학과나 통합 후 학과에 확대하지 않는다.
- 수치 충족이 최종 졸업 가능을 뜻하지 않는다. 편입·전과·다전공·학적회복 및 필수 세부 조건은 별도 확인 항목으로 유지한다.

## 적재 결과

기존 DB 백업 후 해당 학과만 선택해 기준 1행, 새 안내 문서 1개·문단 8개를 추가했다. 기존 컴퓨터공학과 안내 문단 3개는 보존했다. 다른 학과 기준이나 기존 벡터는 덮어쓰지 않았다.

새 문단 8개는 아직 임베딩 전이다. 이 부분은 챗봇 벡터 검색 보강에만 해당하고 `/graduation`의 DB 학점 조회는 임베딩 없이 즉시 반영된다. GPU 운영 컴퓨터에서 실제 모델로 다음 명령을 실행하면 해당 학과 자료의 빈 임베딩만 채운다.

```bash
python -m server.scripts.load_graduation_catalog --department 컴퓨터공학과 --apply --embed --backup-dir ~/previ-backup
```

기본 실행은 미리보기이며 `--department`로 범위를 제한할 수 있다. 기존 적재 자료의 과거 미확인 안내는 그대로 보존하되 새 2021학번 문서에 확인 근거와 적용 범위를 명시했다.
