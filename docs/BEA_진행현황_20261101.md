### API 파일 로그

백업 29개 제한만으로는 기록이 없는 날의 보관 상한을 지킬 수 없었다. API 전용 핸들러가 시작할 때와 매 60초에 회전·정리를 수행한다. 보관 파일의 수정 시각이 29일을 넘으면 정리하여, 정상 실행 중 점검 간격을 포함해 30일 전에 삭제한다. `api.log.YYYY-MM-DD` 파일만 대상으로 삼는다.

공용 journald·다른 사용자의 로그는 변경하지 않았다. **API가 중지돼 있거나 파일 권한·디스크 오류가 있으면 삭제를 보장할 수 없다.** 다음 API 시작 시 정리를 다시 수행한다. 기존 journald 기록과 ngrok 자체 기록은 별도이며 학교 관리자 확인이 필요하다.
