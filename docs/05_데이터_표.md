# 데이터 표 (초안)

> **상태: 초안 · 조장 확인 전.** BE A가 Supabase에 표를 만들면서 다듬고, 바뀐 내용을 이 문서에 반영합니다.

Supabase 데이터베이스에 만드는 표 목록입니다. 엑셀 시트 하나가 표 하나라고 생각하면 됩니다.
모든 표에는 `id`(번호)와 `created_at`(만든 시각)이 기본으로 있어서 아래에서는 생략했습니다.

## 학생 정보

| 표 | 칸 | 설명 |
|---|---|---|
| **profiles** | user_id | Supabase 로그인 계정과 연결 |
| | nickname, department, minor | 이름(별명), 학과, 부전공 |
| | grade, semester, status | 학년, 학기, 학적 상태(enrolled/leave/returned) |
| | admission_year, interests | 입학년도(학번 전체는 받지 않음), 관심사 목록 |
| | consent_agreed_at | 개인정보 동의 시각 |
| | notify_notice, notify_deadline, notify_calendar, notify_chat, notify_time | 알림 종류별 켜짐, 알림 받을 시간 |
| | push_token | 이 휴대폰으로 알림을 보낼 주소 |
| **grades** | user_id, term, course_name, credits, grade, area | 학생이 직접 입력한 성적 |
| **timetable** | user_id, course_id(없으면 직접 입력), course_name, credits, times | 시간표 |

## 학교 정보 (BE가 스크립트로 넣음)

| 표 | 칸 | 설명 |
|---|---|---|
| **courses** | name, credits, area, times | 과목 검색용 과목 목록 |
| **grad_requirements** | department, admission_year, total_credits, areas, required_courses, certifications | 학과·입학년도별 졸업 기준 (2개 학과만) |
| **academic_calendar** | title, start_date, end_date, target_grades | 학사일정 |
| **documents** | title, url, kind(학사요람/규정/공지) | 챗봇이 근거로 쓰는 문서 |
| **doc_chunks** | document_id, content, embedding | 문서를 문단으로 나눈 것 + 검색용 숫자(벡터) |

## 공지와 비서 계산 결과

| 표 | 칸 | 설명 |
|---|---|---|
| **notices** | board_post_id | 게시판 글 번호 (같은 글을 두 번 수집하지 않게) |
| | title, body, url, posted_at | 원문 |
| | category, summary, deadline, documents | AI가 정리한 것 |
| | target, conditions | AI가 뽑은 대상(학년·학과·학적)과 장학 조건(평점·소득분위 등) |
| **eligibility** | user_id, notice_id, verdict, reasons | 학생별 공지 판정 결과와 근거 |
| **todos** | user_id, type, title, due_date, reason, link, source_kind, source_id, priority, done, done_at | 할 일 |
| **scholarship_applications** | user_id, notice_id, applied_at | 장학 신청 완료 기록 (같은 알림 재발송 방지) |
| **briefings** | user_id, date, text, menu_status, suggested_questions | 학생별 오늘 브리핑 |

## 챗봇과 알림

| 표 | 칸 | 설명 |
|---|---|---|
| **conversations** | user_id, title, pinned | 대화 묶음 |
| **messages** | conversation_id, role, text, cards, sources, actions | 대화 속 메시지 |
| **unanswered_questions** | user_id, message_id, question | 챗봇이 "모른다"고 한 질문 (나중에 관리자 기능에서 사용) |
| **notifications** | user_id, type, title, target_id, read, sent_at | 보낸 알림 기록. 보내기 전에 같은 사람·같은 type·같은 target_id가 있으면 보내지 않음 |

## 지켜야 할 것
- 학생은 **자기 데이터만** 보고 고칠 수 있게 Supabase 접근 권한(RLS)을 겁니다.
- 계정을 지우면 그 학생의 모든 줄(성적 포함)이 함께 지워지게 연결합니다.
- 분실물 표는 분실물 작업을 시작할 때 설계합니다.
