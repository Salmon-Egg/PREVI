# 서경 AI 비서 기획안

Oct 15, 2026 · @연어알

## 1. 취지

서경 AI 비서는 **학생이 행정 정보를 찾아다니는 대신, AI 비서가 내 상황에 맞는 일을 먼저 찾아 알려 주는 앱**입니다. 대상은 1\~4학년 전체 학생입니다.

### 왜 만드는가

- **정보가 흩어져 있습니다.** 학사·장학 정보가 학교 공지, 학과 홈페이지, 학사요람 PDF, 종합정보시스템, 단톡방에 나눠져 있습니다.
- **내가 대상인지 직접 판단해야 합니다.** 같은 장학 공지라도 학년, 직전 학기 학점, 소득분위에 따라 대상이 달라서, 학생이 원문을 읽고 자기 조건과 맞춰 봐야 합니다.
- **그 결과 마감과 요건을 놓칩니다.** 장학 신청 마감을 지나치거나, 졸업 요건 누락을 4학년 2학기에야 발견합니다.
- **행정팀에는 같은 문의가 반복됩니다.** 공지에 이미 있는 내용을 매 학기 같은 시기에 다시 묻습니다.

근거로 쓸 수치(마감을 놓친 경험 비율, 정보를 찾는 데 걸리는 시간 등)는 설문으로 보강해야 합니다.

### 어떻게 해결하는가

AI 두 개가 역할을 나눌 맡습니다.

- **AI 비서 에이전트(메인)**: 학교 공지와 내 정보를 매일 대조합니다. 마감, 자격, 누락을 찾아 학생이 묻기 전에 먼저 알려 줍니다.
- **AI 챗봇**: 궁금한 것을 물으면 학교 문서를 근거로, 내 상황에 맞춰 답합니다. 출처도 함께 보여 줍니다.

공모전 주제인 "탐지·예측·해결"과는 이렇게 연결됩니다.

| 주제 | 서경 AI 비서에서는 |
| --- | --- |
| 탐지 | 내가 해당되는 공지, 빠진 졸업 요건, 시간표 문제를 찾아냄 |
| 예측 | 마감을 놓칠 위험, 졸업이 늦어질 위험, 다음 주에 몰릴 문의를 미리 알려 줌 |
| 해결 | 할 일 순서, 신청 방법, 근거 문서를 한 번에 제시함. 실제 신청은 학생이 직접 함 |

### 기능 흐름

&#91;embedded content: 전체 플로우 · 에이전트(위)와 챗봇(아래)\]

윗줄은 학생이 묻지 않아도 돌아가는 에이전트 흐름이고, 아랫줄은 학생이 물을 때 동작하는 챗봇 흐름입니다. 두 흐름은 내 상황 계산 결과를 함께 씁니다.

1. **처음 설정**: 학생이 학적·성적·시간표를 입력하고, AI 비서가 쓸 정보에 동의합니다.
2. **매일 점검**: 에이전트가 새 공지를 읽고 내 정보와 대조합니다.
3. **브리핑**: 급한 순서로 오늘 챙길 일을 알려 줍니다.
4. **자세히 보기·질문**: 항목을 누르면 요약과 원문을 보고, 더 궁금하면 챗봇에 이어서 물습니다.
5. **처리**: 학생이 신청을 마치고 완료를 체크합니다.
6. **갱신**: 성적이나 학적이 바뀌면 에이전트가 졸업 요건과 자격을 다시 계산합니다.

챗봇이 답하지 못한 질문은 학생지원팀에 모입니다. 담당자가 문서를 보강하면 다음부터는 챗봇이 답할 수 있습니다.

## 2. 기능 나열

기능은 6개 묶음, 24개입니다. 그중 필수는 15개입니다. 중심은 **AI 비서 에이전트**이고, 챗봇이 이를 보완합니다. 내 학사 정보는 에이전트가 판단할 때 쓰는 재료입니다. 분실물은 부가 기능입니다.

## 3. 페르소나

대상은 1\~4학년 전체입니다. 학년마다 챙겨야 할 행정이 다르기 때문에, 같은 앱이라도 에이전트가 골라 주는 내용이 달라집니다. 이름은 모두 가상입니다.

### 1학년 · 김새내 (소프트웨어학과, 신입생)

- **상황**: 학교 시스템을 처음 씁니다. 수강 정정, 교양 필수, 학사요람 같은 말이 낯설습니다.
- **불편**: 어디서 무엇을 봐야 하는지 몰라서 단톡방과 선배에게 물어봅니다.
- **AI 비서가 하는 일**: 신입생에게 필요한 일정만 골라 알려 줍니다. 학사 용어도 챗봇이 쉽게 풀어 줍니다.
- **대표 장면**: "수강 정정이 뭐야? 언제까지야?" → 뜻, 기간, 방법을 출처와 함께 답합니다.

### 2학년 · 이도전 (경영학 부전공 고민)

- **상황**: 전공에 익숙해졌고, 부전공이나 복수전공을 고민합니다. 성적 장학금에도 관심이 있습니다.
- **불편**: 부전공 신청 조건과 마감, 장학금 성적 기준을 공지마다 따로 찾아야 합니다.
- **AI 비서가 하는 일**: 내 평점으로 신청할 수 있는 장학금과 부전공 신청 조건을 대조해 줍니다.
- **대표 장면**: 브리핑에 "성적우수 장학금 신청 가능, D-5"가 뜨고, 누르면 조건을 충족하는 근거가 나옵니다.

### 3학년 · 박바뻐 (근로·대외활동 병행, 휴학 고민)

- **상황**: 수업, 근로, 대외활동으로 바빠서 공지를 거의 못 봅니다. 다음 학기 휴학을 고민합니다.
- **불편**: 마감을 자주 놓칩니다. 휴학하면 장학금과 복학 절차가 어떻게 되는지 알기 어렵습니다.
- **AI 비서가 하는 일**: 아침 브리핑 하나로 오늘 할 일을 끝내 줍니다. 학적 상태를 바꾸면 관련 규정과 기한도 자동으로 안내합니다.
- **대표 장면**: "휴학 중에도 장학금 신청 돼?" → 규정을 근거로 답하고, 복학 신청 기한을 할 일에 넣어 줍니다.

### 4학년 · 홍길동 (졸업 앞둔 학생)

- **상황**: 졸업까지 9학점이 남았고, 졸업작품 심사와 취업 준비를 함께 합니다.
- **불편**: 졸업 요건 중 빠진 게 있는지 확신이 없습니다. 심사 신청 마감을 놓치면 졸업이 한 학기 늦어집니다.
- **AI 비서가 하는 일**: 내 성적과 학사요람을 대조해 남은 요건을 계산하고, 졸업 관련 마감을 가장 먼저 알려 줍니다.
- **대표 장면**: "졸업까지 뭐가 남았어?" → "2가지 남았어요. 졸업작품 심사 신청이 오늘 마감이에요."

### 보조 사용자 · 학생지원팀 담당자

학생들의 반복 문의에 시간을 씁니다. 챗봇이 답하지 못한 질문을 모아 보고, 문서를 보강해 같은 문의를 줄입니다.

## 4. 연계 기능

기능들이 따로 노는 것이 아니라, 하나의 변화가 다른 기능을 자동으로 움직입니다. 단순한 게시판·조회 앱과 구별되는 지점이 바로 여기입니다.

### 4-1. 앱 안 기능끼리의 연결

| 이런 일이 생기면 | AI 비서가 이어서 하는 일 | 학생이 보는 결과 |
| --- | --- | --- |
| 성적을 입력·수정함 | 졸업 요건과 장학 자격을 다시 계산 | 부족한 요건이나 새로 신청 가능한 장학금이 할 일에 추가됨 |
| 새 장학 공지가 올라옴 | 조건을 뽑아 내 정보와 대조 | 대상이면 브리핑에 뜨고, 누르면 공지 요약으로 이동 |
| 시간표에 과목을 추가함 | 시간 중복·학점 상한을 확인하고 졸업 학점에 반영 | 문제가 있으면 바로 안내, "졸업까지 6학점" 같은 변화 표시 |
| 학적 상태를 휴학으로 바꿈 | 휴학 관련 규정(장학금 영향, 복학 기한)을 찾음 | 복학 신청 기한이 할 일에 등록됨 |
| 브리핑·할 일 항목을 누름 | 그 항목의 내용을 챗봇에 넘겨줌 | 채팅에서 처음부터 설명할 필요 없이 이어서 질문 |
| 챗봇 답변에서 "마감 알림 받기"를 누름 | 마감을 할 일에 등록 | 전날·당일 알림 |
| 할 일을 완료로 체크함 | 신청 내역에 기록 | 같은 알림이 다시 오지 않음 |
| 챗봇이 답하지 못함 | 미응답 질문으로 관리자에게 전달 | 담당자가 문서를 보강하면 다음부터 답변됨 |
| 담당자가 대상 지정 공지를 보냄 | 조건에 맞는 학생만 골라 전달 | 해당 학생의 브리핑에만 표시 |
| (부가) 내 분실 신고와 비슷한 습득물이 들어옴 | 일치율을 계산 | 브리핑에 "비슷한 물건이 들어왔어요" 표시 |

### 4-2. 외부 시스템 연동

공모전 단계에서는 학교 시스템에 접근할 수 없습니다. 그래서 직접 입력과 가상 데이터로 시연하고, 실제 연동은 도입 단계의 확장 계획으로 제시합니다.

| 연동 대상 | 가져오는 것 | 공모전(시연) | 실제 도입 시 |
| --- | --- | --- | --- |
| 학교 홈페이지 공지 | 학사·장학 공지 | 공지 20\~30개 수동 수집 | 자동 수집(학교와 협의) |
| 종합정보시스템 | 학적, 성적, 수강 내역 | 학생 직접 입력, 가상 학생 데이터 | 학교 시스템 연동으로 자동 반영 |
| 학사요람·규정 | 졸업 요건, 학사 규정 | PDF 업로드 | 학기마다 갱신 |
| 학교 통합 로그인 | 본인 인증 | 테스트 계정 | 학교 계정으로 로그인(SSO) |
