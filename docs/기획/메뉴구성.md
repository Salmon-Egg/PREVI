# 서경 AI 비서 – 메뉴 구성

> 기준일 2026-10-16 · 홈 화면은 완성본 기준
> 표시: `기존` 시안 있음 · `수정` 시안 고쳐야 함 · `신규` 새로 그려야 함

## 한눈에 보기

```
홈 (AI 비서)
├─ 상단: 알림 · 프로필(마이·설정)
├─ 캐릭터 + 말풍선 ─────────────→ AI 채팅
├─ 오늘 챙길 일 ────────────────→ 할 일
├─ 어떤 도움이 필요하신가요? (2×2)
│   ├─ 내 학업      (시간표 · 성적 · 졸업)
│   ├─ 장학금
│   ├─ 학사 행정    (공지 · 일정 · 학적)
│   └─ 캠퍼스 생활  (분실물, 부가)
└─ 하단 질문창 + 추천 질문 ─────→ AI 채팅

관리자(학생지원팀): 처리할 일 · 챗봇 관리 · 공지 발송 · 분실물 관리
```

**원칙**: 홈의 모든 진입점은 비서가 판단한 결과를 먼저 보여 준다. 메뉴 칸에도 비서 한 줄 상태를 표시한다.

---

## 1. 홈 (완성)

| 영역 | 역할 | 연결 |
|---|---|---|
| 알림 아이콘 | 비서가 보낸 알림 | 알림 센터 |
| 프로필 아이콘 | 내 정보·설정 | 마이·설정 |
| 캐릭터 + 말풍선 | 오늘 요약 한 줄 (예: "오늘 마감 2개, 장학금 1개 신청 가능해요") | AI 채팅 |
| 오늘 챙길 일 | 급한 순 D-day 목록, 다음 일정 카드 | 할 일 상세 / 할 일 목록 |
| 어떤 도움이 필요하신가요? | 메뉴 4칸, 칸마다 비서 한 줄 | 각 메뉴 |
| 하단 질문창 + 추천 질문 | 학년·상황별 추천 질문 | AI 채팅 |

## 2. 메뉴 4칸

| 버튼 | 칸에 보이는 비서 한 줄 (예시) | 들어가는 기능 |
|---|---|---|
| 내 학업 | 졸업까지 9학점 | 시간표·수강, 성적, 졸업 요건 |
| 장학금 | 신청 가능 1건 · 오늘 마감 | 맞춤 장학금, 공지 요약, 신청 내역 |
| 학사 행정 | 새 공지 2건 | 나에게 해당하는 공지, 학사 일정, 휴·복학 |
| 캠퍼스 생활 | 비슷한 습득물 1건 | 분실물 (부가 기능) |

> 대안(3칸): 캠퍼스 생활을 빼고 분실물은 채팅·추천 질문으로만 진입. 분실물을 시연하지 않을 때 선택.

|---|---|---|---|

| T-2 | 할 일 상세 | 왜 해야 하는지 근거, 마감, 신청 링크, "채팅으로 묻기" | `신규` |
