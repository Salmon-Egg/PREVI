# 서경 AI 비서 시연 사이트

예시 데이터로 모든 화면을 눌러 볼 수 있는 웹 버전입니다. 서버가 없어도 됩니다.

- **링크로 보기**: https://claude.ai/artifact/KSy1QoVa8q13N759se35Pp (공유받은 사람만 열림)
- **내 PC에서 보기**: `시연_사이트_열기.bat` 더블클릭 → 브라우저에서 http://localhost:8095 가 열림
  - `index.html`을 직접 더블클릭하면 화면이 안 바뀝니다(브라우저가 파일 주소에서 화면 이동을 막음). 꼭 bat 파일로 여세요.
- **다시 만들기**: `app` 폴더에서 `npm run build:demo`

`index.html`은 빌드 결과물(4MB)이라 깃허브에는 올리지 않도록 `.gitignore`에 넣어 두었습니다.
